# Audio Kalor Quest

Letakkan file musik latar bernama `background.mp3` di folder ini:

`assets/audio/background.mp3`

Musik diputar berulang saat permainan dimulai dan tombol speaker aktif. Gunakan tombol speaker untuk menjeda atau melanjutkan musik dan efek suara.

Efek suara permainan sudah dibuat langsung oleh game, jadi tidak perlu menambahkan file efek suara. Untuk memakai musik lain, ganti file `background.mp3` dengan file audio milikmu dan gunakan nama yang sama.
